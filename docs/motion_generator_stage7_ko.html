Task 7.2 결과 (2026-07-13)

Generator가 episode reset 때 뽑은 unit world-heading d_xy와 simulator의 실측 world-frame root velocity v_xy를 사용해 다음 식을 그대로 구현했다.

r_heading = dot(v_xy, d_xy) / (norm(v_xy) + epsilon)

Body-frame observation velocity를 재사용하지 않고 robot_root_states[:, 7:9]를 직접 사용하므로 target과 velocity 좌표계가 모두 world frame이다. 정지 시 reward는 0이며 aligned/opposite 방향은 각각 거의 +1/-1이다.

파일변경
managers/reward/terms/heading.pybatch heading 식과 방향 오차의 공용 tensor 구현; shape·epsilon 검사
managers/reward/terms/wbt.pymotion_heading_alignment reward term, generated command type/config 검사

구현 선택: 논문은 reward weight, denominator epsilon, 정지 상태의 error convention을 공개하지 않는다. 현재 기본값은 terrain preset weight 1.0, epsilon 1e-6다. 방향이 정의되지 않는 속도 <0.05 m/s에서는 metric만 π/2로 기록하며 reward 식은 바꾸지 않는다. 세 값 모두 config/CLI로 조절 가능하다.

Task 7.1 결과 (2026-07-13)

Terrain tracker의 네 proprioceptive signal만 현재 frame을 포함해 5 frame으로 확장했다. 정책 주기 50 Hz 기준 순서는 [t-4, t-3, t-2, t-1, t]이며 가장 오래된 frame과 현재 frame의 간격은 0.08 s다. Generated reference와 289차원 terrain scan은 현재 frame 하나만 유지한다.

Checkpoint 호환 layout

ObsTermCfg.history_length를 추가하되, override가 없는 모든 기존 group은 종전 group-level layout을 그대로 사용한다. Selective-history group은 기존 current-frame vector를 변형하지 않은 prefix로 두고 선택된 term의 과거 4 frame만 suffix로 붙인다. 따라서 Stage-6 input weight를 순열 없이 보존할 수 있다.

actor : old Stage-6 prefix [0:443]
        projected-gravity current [443:446]
        past proprio suffix [446:702]  -> total 702

critic: old Stage-6 prefix [0:575]
        projected-gravity current [575:578]
        past proprio suffix [578:834]  -> total 834

처음 관측하는 과거 slot은 0으로 padding한다. 일부 env만 reset되면 deque 전체를 지우지 않고 해당 env row만 0으로 초기화해 다른 env의 history를 보존한다. Bootstrap용 modify_history=False 계산은 deque를 전진시키지 않는다.

구현 선택: 논문은 tracker history의 정확한 flatten 순서, 초기 padding, observation noise를 공개하지 않는다. 이 구현은 current prefix 뒤에 term-name 순서의 oldest-to-newest 과거 suffix를 사용하고, projected gravity의 추가 noise는 0으로 둔다. Selective suffix는 현재 symmetry augmentation의 직사각형 frame layout과 호환되지 않으므로 use_symmetry=True이면 명시적으로 중단한다. 현재 WBT preset은 symmetry를 사용하지 않는다.

Warm-start와 검증

첫 Linear와 Adam moment는 기존 append-only 규칙으로 0 suffix를 붙인다. Empirical normalizer는 새 terrain/gravity current 채널에는 identity 통계를 쓰되, base angular velocity·joint position·joint velocity의 과거 244개 열에는 대응 current-feature의 mean/variance/std를 복사한다. 기존 scalar sample count도 보존하므로 신규 terrain/gravity 통계의 적응은 느리며, bounded raw 입력으로 exact resume를 우선한 선택이다.
