Task 8.1 결과 (2026-07-13)

Noise는 정규화된 tensor가 아니라 물리 단위의 condition에만 적용한다. 과거 2 frame의 root position/orientation, joint position, tracked body position과 현재 terrain scan을 perturb하며, 미래 ground truth와 loss용 terrain은 clean 상태를 유지한다. 기존 preset의 모든 기본값은 0이어서 Stage 1–7 동작과 checkpoint를 보존한다.

항목terrain_robust_4090 값단위/방식
root position0.01m, Gaussian std
root orientation0.02rad, axis-angle left composition
joint position0.01rad, Gaussian std
body position0.01m, Gaussian std
terrain point height0.01m, independent Gaussian std
terrain point dropout0.05확률, dropped point는 0 m
terrain height bias0.01m, scan별 Gaussian std
terrain local xy / yaw0.02 / 0.02m / rad, bilinear scan warp

Quaternion은 내부 convention인 wxyz로 axis-angle noise를 합성한 뒤 매번 unit norm으로 정규화하고, 시간축 sign branch도 연속되게 유지한다. Terrain warp는 Stage 3/6과 같은 17×17, x-major/y-fastest layout을 사용한다. 학습 때만 자동 적용되며 inference에는 암묵적으로 noise를 넣지 않는다.

동일 protocol 전후 비교

기존 terrain_4090/final.pt와 그 checkpoint에서 10,000 step fine-tune한 robust+FK 모델을 같은 validation batch 256, 8 batches, seed 123, 2-step DDIM으로 평가했다. Clean/noisy sampling은 exact same initial diffusion noise를 공유한다.

checkpointclean / noisy total lossclean / noisy MPJPEnoisy-clean MPJPE gap
기존 terrain0.009627 / 0.0122020.03458 / 0.06018 m0.02559 m
robust+FK 10k0.009752 / 0.0101760.03860 / 0.05000 m0.01140 m

Noisy MPJPE는 0.06018→0.05000 m, noise gap은 0.02559→0.01140 m로 감소했고 모든 sample/loss가 finite였다. 따라서 configured noisy condition에서 붕괴하지 않았다. 반면 clean MPJPE는 0.03458→0.03860 m로 나빠졌다. 이것은 robustness와 clean accuracy 사이의 측정된 trade-off이며, 단일 seed 결과다.

Task 8.1 완료: 모든 perturbation 크기를 config화하고 quaternion/terrain contract를 테스트했으며, 같은 random draw를 쓰는 clean/noisy validation에서 noise gap 감소와 finite motion을 확인했다.

Task 8.2 결과 (2026-07-13)

G1ForwardKinematics는 HoloSoma의 29-DoF MuJoCo tree를 torch tensor 연산만으로 전개해 predicted root pose와 29 joint angle에서 14 tracked body origin을 계산한다. 임의 batch 차원을 지원하고 root quaternion은 wxyz다. 상수는 g1_29dof.xml에서 추출했으며 source SHA-256 8c586e4747da85804180fe44d8692e0fd8231356728b6327e256dca498087a78와 joint/body name을 fail-fast로 검사한다.

L_FK = mean || predicted_body - FK(predicted_root, predicted_joint)||²
loss.fk_consistency = 0.1  # terrain_robust_fk_4090 only

기존 Stage 1–7 preset은 FK weight 0을 유지한다. Robust+FK preset만 weight 0.1로 별도 제공하며 fk_consistency와 해석 가능한 fk_body_error_m를 train/validation/TensorBoard에 기록한다.

256 random pose의 MuJoCo parity는 float64 최대 L2 error 1.095e-15 m, float32 최대 6.35e-7 m였다. 실제 train dataset 8 window를 학습 전에 검사한 calibration error는 mean 6.324e-8 m, max 3.806e-7 m로 1 mm fail-fast tolerance를 통과했다.

metric기존 terrain checkpointrobust+FK 10k변화
clean FK body error0.00698697 m0.00690262 m−0.00008435 m (−1.2%)
noisy FK body error0.00717166 m0.00694394 m−0.00022772 m (−3.2%)

FK error는 두 조건 모두 작지만 일관되게 감소했다. 즉 joint/root head와 independently predicted body-position head 사이의 측정된 충돌은 줄었다. 이 수치만으로 접촉 안정성이나 obstacle 통과가 개선됐다고 주장하지 않는다.

구현 선택: 논문은 정확한 robot FK model, tracked-link subset, FK loss reduction, weight, calibration tolerance를 공개하지 않는다. 29-DoF HoloSoma MJCF, 14 body origins, coordinate MSE, weight 0.1, tolerance 1 mm는 모두 이 재현의 구현 선택이다.
Task 8.2 완료: torch FK의 MuJoCo parity와 end-to-end gradient를 검증했고, 10k fine-tune 뒤 clean/noisy FK conflict metric이 모두 감소했다.

Task 8.3 결과 (2026-07-13)

같은 walk4 history(start 5750), 같은 anchor heading [0.976827, -0.214030], seed 123, 2-step DDIM을 고정하고 scan만 flat / 0.30 m / 0.60 m로 바꿨다. 장애물은 anchor-local x=[0.30, 0.90], y=[−0.40, 0.40]의 63 grid point다. 각 condition은 batch-size 1의 독립 sampler call로 실행해 condition 순서가 RNG batch semantics를 바꾸지 않게 했다.

robust+FK metricflat0.30 m0.60 m
forward displacement0.39762 m0.29656 m0.25834 m
root z, final0.76797 m0.77176 m0.77946 m
left / right foot z max0.15133 / 0.12808 m0.13856 / 0.12185 m0.12956 / 0.10174 m
left / right knee flexion max1.40717 / 1.24641 rad1.36853 / 1.15923 rad1.35608 / 0.96134 rad
body-origin penetration proxy max00.25264 m0.36192 m
body-origin penetration proxy rate03.714%9.714%

Configured threshold 기준으로 foot height, root height, knee flexion, forward displacement 중 하나 이상이 충분히 변해 meaningful_physical_response=true다. Root final height는 obstacle 높이에 따라 단조 증가했고 진행 거리는 감소했다. 그러나 foot max height와 knee max flexion은 기대와 반대로 감소했고 penetration proxy는 증가했다. 기존 terrain checkpoint의 0.60 m max proxy 0.43775 m보다 robust+FK의 0.36192 m는 낮지만, 안전한 obstacle motion이라고 볼 수준은 아니다.

Proxy의 한계: 이 수치는 generated 14 body origin과 rectangular scan height의 차이다. Collision shape, mesh intersection, contact force를 계산하지 않으므로 실제 simulator penetration이 아니다. 현재 결론은 “terrain condition에 민감하게 반응한다”까지이며, “장애물을 제대로 넘는다”는 체크하지 않는다. 0.60 m는 학습 분포 밖 stress test다.

남은 문제와 다음 단계

  • Clean accuracy가 약 4 mm 나빠졌으므로 condition-noise 크기와 FK weight는 multi-seed ablation이 필요하다.
  • 0.30/0.60 m obstacle에서 발 높이·무릎 굴곡이 증가하지 않고 body-origin penetration proxy가 커진다. Height scan conditioning만으로는 원하는 climbing policy가 형성되지 않았다.
  • 후속 terrain feasibility gate에서 실제 climb_09 장기 rollout을 MuJoCo collision shape로 검사했고 최대 0.260 m 침투와 joint-limit 위반으로 실패했다. Stage 8의 meaningful_physical_response는 feasibility pass가 아니다.
  • Generator의 terrain gate를 개선·통과한 뒤에만 Stage 9의 actuator/contact를 포함한 dynamic tracker 평가를 재개한다.
