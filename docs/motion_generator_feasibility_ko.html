Terrain Feasibility Gate

최종 robust+FK generator의 실제 지형 rollout을
MuJoCo collision geometry와 직접 재생으로 검증

현재 판정: FAIL · dynamic feasibility 미평가
판정검증 범위실측 결과 생성정량 검사직접 재생 W&B한계와 다음 단계

1. 결론

현재 generator motion은 이 지형에서 feasible하지 않다. 최신 terrain_robust_fk_4090/final.pt를 2-step DDIM으로 실제 climb_09 박스 scan에 조건화해 242 frame을 생성했다. MuJoCo collision shape 기준 최대 지형 침투는 0.2603 m, strict 5 mm gate 초과 frame rate는 40.91%였고 그중 5 cm 초과 severity rate는 35.95%였다. 오른쪽 ankle-roll은 최대 0.02153 rad joint limit를 넘었고, generator body head와 qpos 기반 MuJoCo FK의 최대 오차도 0.03265 m였다.

Quaternion은 정상이고 재계획 경계가 유일한 큰 불연속 원인은 아니었다. 실패의 핵심은 obstacle에 접근한 뒤 발과 무릎 collision shape가 박스 내부로 깊게 들어가는 것이다. 그러므로 이 generator를 고정한 채 장시간 scratch PPO부터 돌리는 것은 현재 우선순위가 아니다.

  • ☑ 최종 checkpoint로 2-step 실제 terrain-conditioned rollout 생성
  • ☑ quaternion, joint limit, 속도/가속도, 재계획 경계 검사
  • ☑ predicted body head ↔ MuJoCo FK 정합 검사
  • ☑ 실제 URDF box collision depth 검사
  • ☑ 동일 source segment를 같은 scene에서 비교
  • ☑ headless GIF 실제 생성, interactive MuJoCo의 start-frame/playback 경로 회귀 테스트 및 사용자 실행 명령 준비
  • ☑ JSON/NPZ/GIF/scene/source/synthetic stress를 W&B run + artifact로 기록
  • ☐ actuator, torque, balance, friction을 포함한 dynamic feasibility

7. W&B 기록

실행 결과를 W&B run 1gzs0tq5에 기록했다. Remote artifact v0는 12파일: schema-v3 report, qpos/raw, 정상 timing의 full/slow GIF, robot XML, terrain URDF+OBJ, evaluator/viewer source, synthetic stress JSON/NPZ다. Report는 checkpoint와 reference NPZ를 재배포하지 않고 SHA-256만 기록하며 총 13개 local provenance file을 hash한다. hsretargeting env에는 wandb가 없으므로 online logging 재실행은 hsmujoco env를 사용한다.

8. 남은 한계와 다음 단계

  1. 단일 clip/seed: 이 결과는 실패를 입증하기에는 충분하지만 전체 분포의 success rate는 아니다. climb/scene별 여러 history·seed를 batch gate로 확장해야 한다.
  2. Box approximation: 실제 mesh가 아니라 OmniRetarget의 box 근사와 G1 MJCF collision shape를 사용했다.
  3. Source도 collision-perfect가 아님: climbing source의 손 contact가 box 안으로 최대 약 8.1 cm 들어가므로 contact rate만으로 generated/source 우열을 말하지 않는다.
  4. Collision metric 범위: 값은 MuJoCo pairwise contact signed gap이며 일반 mesh SDF가 아니다. Ground와 이름이 붙은 terrain box만 세고 robot self-collision은 제외한다.
  5. URDF 범위: viewer/evaluator는 world 좌표가 OBJ vertex에 baked되고 origin/rpy가 0인 OmniRetarget 8-vertex box만 지원한다. 다른 URDF는 조용히 오정렬하지 않고 오류를 낸다.
  6. 동역학 미평가: 이 검사를 통과한 뒤에만 actuator가 있는 IsaacLab tracker에서 fall, torque, slip, contact, obstacle success를 평가한다.
  7. Generator 개선 우선: joint-limit loss/clamp, qpos-FK body consistency, collision-shape 또는 sole-point terrain loss, obstacle-height-balanced training, multi-step rollout loss를 먼저 검토한다.
학습 결정: 2026-07-14에 시작했던 full-terrain closed-loop scratch30k run은 이 gate를 우선하기 위해 약 97 update에서 의도적으로 중단했다. 해당 run은 성능 결과가 아니라 initialization diagnostic으로만 보존한다. Generator gate를 통과하기 전에는 같은 30k production을 재개하지 않는다.
