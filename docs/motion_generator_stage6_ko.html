실행 명령

PY=~/.holosoma_deps/miniconda3/envs/hssim/bin/python
GEN=logs/motion_gen/terrain_4090/checkpoints/final.pt
SEED=data/motion_gen/processed_paperscale/lafan1_walk4_subject1.npz
TRACKER=logs/WholeBodyTracking/20260711_122501-g1_29dof_wbt_gen_manager-locomotion/model_12000.pt

# 기존 flat regression (64 env × 2 iter)
$PY src/holosoma/holosoma/train_agent.py exp:g1-29dof-wbt-gen logger:disabled \
  --training.num-envs 64 --algo.config.num-learning-iterations 2 \
  --algo.config.save-interval 999999 \
  --command.setup-terms.motion-command.params.motion-config.generator-checkpoint=$GEN \
  --command.setup-terms.motion-command.params.motion-config.motion-file=$SEED

# 별도 terrain + 기존 tracker resume (64 env × 추가 2 iter)
$PY src/holosoma/holosoma/train_agent.py exp:g1-29dof-wbt-gen-terrain logger:disabled \
  --training.num-envs 64 --training.checkpoint=$TRACKER \
  --algo.config.num-learning-iterations 2 --algo.config.save-interval 999999 \
  --command.setup-terms.motion-command.params.motion-config.generator-checkpoint=$GEN \
  --command.setup-terms.motion-command.params.motion-config.motion-file=$SEED
실측 통과: flat run 20260713_072831-g1_29dof_wbt_gen_manager-locomotion과 terrain run 20260713_072855-g1_29dof_wbt_gen_terrain_manager-locomotion이 각각 2 iteration을 오류 없이 완료했다. Terrain run에서 custom mesh 생성, terrain origin 동기화, generator checkpoint step 200,000, trainable generator parameter 0, tracker model_12000.pt 및 optimizer 복원, 최종 model_12001.pt 저장을 로그로 확인했다.

좌표와 현재 한계

  • Procedural terrain은 하나의 world-frame global mesh다. 각 env의 reset root와 generator seed body 위치는 같은 terrain tile world origin을 사용하도록 동기화했다.
  • terrain_locomotion_mix 선택은 Task 6.1의 실행 분리용 구현 선택이다. 현재 구성(flat/rough/low-obstacles)은 최종 box/stair/hurdle curriculum이 아니며 Task 7.3에서 교체한다.
  • Task 6.1에서는 observation shape(Actor 154, Critic 286)을 유지해 Stage-5 tracker를 strict-load했다. Generator 입력은 아직 zero scan이며 Task 6.2–6.3에서 실제 scan으로 교체한다.
